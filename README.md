# MultichannelPlayer
Multichannel Player is a SuperCollider app for playing multichannel music from mono files, with 4, 8, 16, 18 or more channels. Build playlists, set and remember track levels, test speakers, and auto-level every piece to equal loudness. Listen in direct multichannel, 3D Ambisonics, VBAP, binaural, stereo or B-format.
